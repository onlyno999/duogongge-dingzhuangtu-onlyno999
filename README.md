# 多宫格定妆图

Agent 技能包：用户上传人物图片（单张头像/照片，或现成的定妆卡），可选附一条本人音轨，产出「多宫格定妆图」：

- 照片区五格：正面全身（无头）／侧面全身（无头）／背面全身／右上正面脸部特写／右下四分之三侧脸特写，灰底影棚风；容貌以原图为准 1:1 锁死不许改变，格 1、格 2 脖子贴上沿、身体占满格高。
- 照片区下方永远留声纹区：高度＝照片高 × 566/1482（占全图 27.6%）。没有音轨就留空带；有音轨就在空带原位填声纹——波形用该音轨真画、原话用双模型 ASR 识别放右下角、语言标签按音轨实测。

铁律与完整流程见 [SKILL.md](SKILL.md)，声纹区生成脚本见 [scripts/build_voiceprint_card.py](scripts/build_voiceprint_card.py)。
